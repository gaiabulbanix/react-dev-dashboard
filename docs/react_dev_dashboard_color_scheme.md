# Dashboard Color Scheme & Style Guide

## Theme

**Green + Ube Purple + Dark Neutral**

Modern, polished SaaS/dashboard aesthetic. Green is the primary action color; ube purple is the secondary accent.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Green | `#22C55E` |
| Secondary | Ube Purple | `#8B5CF6` |
| Background | Dark Background | `#0F1720` |
| Surface | Dark Surface | `#151D25` |
| Primary Text | Soft White | `#F8FAFC` |
| Secondary Text | Slate | `#94A3B8` |
| Soft Neutral | Light Neutral | `#F3F4F6` |

## Color Roles

### Green — `#22C55E`
Use for:
- Primary buttons and calls to action
- Success states
- Completed items
- Positive progress
- Active indicators
- Important highlights

### Ube Purple — `#8B5CF6`
Use for:
- Secondary buttons
- Accent elements
- Selected states
- Charts and visual data
- Supporting highlights

### Dark Background — `#0F1720`
Use for:
- Main page background
- Overall application canvas

### Dark Surface — `#151D25`
Use for:
- Cards
- Panels
- Navigation areas
- Form containers

### Soft White — `#F8FAFC`
Use for:
- Main headings
- Important text
- Primary navigation text

### Slate — `#94A3B8`
Use for:
- Supporting text
- Descriptions
- Metadata
- Less-important labels

## Visual Style

- Dark UI
- Generous spacing
- Rounded cards and controls
- Subtle borders
- Light shadows/glows rather than heavy shadows
- Green as the dominant accent
- Purple as a supporting accent
- Clean, modern SaaS/productivity aesthetic
- Suggested border radius: `12px–16px`

## Component Guidance

### Buttons
- Primary: green background with light text
- Secondary: ube purple background with light text
- Outline: transparent/dark surface with green or purple border
- Destructive: use a separate red semantic color only when necessary

### Cards
- Background: `#151D25`
- Border: subtle neutral/slate
- Heading: `#F8FAFC`
- Supporting text: `#94A3B8`

### Charts
Use green and ube purple as the primary data colors. Avoid introducing many additional colors unless they carry a specific meaning.

## Overall Vibe

**Modern · Focused · Energetic · Personal · Clean**
